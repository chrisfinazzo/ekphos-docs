Canvas provides a spatial workspace for notes, text, links, and groups. Ekphos
reads and writes the JSON Canvas 1.0 format used by `.canvas` files, including
standard colors, card dimensions, connection endpoints, labels, and extension
fields.

## Create a Canvas

Press `n` to open the **New Document** dialog, then press `Tab` or the left and
right arrows until **Canvas** is selected. Enter a name and press `Enter`.
Ekphos adds the `.canvas` extension, creates valid empty JSON Canvas content,
and opens the new Canvas immediately.

An empty Canvas is ready to edit visually. Right-click anywhere in the Canvas
and choose a card type, press `a` to open the same add menu from the keyboard,
or double-click empty space to create a text card immediately. You do not need
to edit JSON to build a Canvas.

## Create and manage cards

Right-click empty space to open the Canvas menu at the pointer. New cards are
centered at that location and saved immediately.

| Menu action        | Result                                                   |
| ------------------ | -------------------------------------------------------- |
| Add text card      | Create a text card and start editing it                  |
| Add file card      | Search the vault, then create a card for the chosen file |
| Add link card      | Create a link card and start entering its URL            |
| Add group          | Create a group and start naming it                       |
| Fit Canvas to view | Reframe all cards and groups                             |

Right-click a card to edit or open it, duplicate it, start a connection, or
delete it. Right-click a connection to delete it. Deleting a card also removes
its attached connections; press `u` to undo if you change your mind.

The menus are fully keyboard-operable. Press `Shift+F10` for the selected card
or connection, move with arrows or `j` / `k`, activate with `Enter` or `Space`,
and close with `Esc`. In the file picker, type to filter the vault, use arrows
or `PageUp` / `PageDown` to move, and press `Enter` to add the selected file.
With a mouse, click once to select a file and double-click it to add the card.

## Supported content

| Card type | Canvas content                               |
| --------- | -------------------------------------------- |
| Text      | Markdown text stored directly in the Canvas |
| File      | A Markdown or supported vault file          |
| Link      | An external URL                             |
| Group     | A labeled region behind related cards       |

Connections attach to the top, right, bottom, or left side of a card. Their
paths stay behind opaque cards, and selected or related connections are
highlighted without changing the stored Canvas data.

## Select, move, and explore

| Key or action                       | Result                               |
| ----------------------------------- | ------------------------------------ |
| Click a card                        | Select the card                      |
| Double-click empty space            | Create and edit a text card          |
| Right-click                         | Open actions for that location       |
| Drag a card                         | Move and save the card               |
| Drag empty space                    | Pan the Canvas                       |
| Middle-button drag                  | Pan from anywhere                    |
| Scroll outside the active editor    | Zoom around the pointer              |
| `j` / `k` or up/down arrows         | Select a card above or below         |
| `Shift+H` / `Shift+L`               | Select a card to the left or right   |
| `Shift` + arrows                    | Pan the Canvas                       |
| `Alt` + arrows                      | Move the selected card               |
| `z i` / `z o`                       | Zoom in or out                       |
| `f`                                 | Fit all Canvas content               |

The footer starts with one compact row so it does not crowd the workspace.
Click **F3 shortcuts** or press `F3` to reveal the complete Canvas shortcut
legend; use the same control again to collapse it.

## Resize cards and groups

Select a card or group to reveal a `◇` handle at each corner. Drag a corner or
any border to resize it. Connected lines follow the border while you drag.

| Resize control                  | Result                                        |
| ------------------------------- | --------------------------------------------- |
| Drag a border                   | Resize from that edge                         |
| Drag a `◇` corner               | Resize width and height together              |
| `Shift` + drag                  | Keep the original aspect ratio                |
| `Alt+Shift` + left/right arrow  | Decrease or increase the width                |
| `Alt+Shift` + up/down arrow     | Decrease or increase the height               |
| `Esc` while dragging            | Restore the size from before the drag         |

The new dimensions are saved when you release the pointer. Resizing while
editing keeps the current draft open and reflows it to the new width.

## Edit card content

Double-click a text, link, or group card to edit it inside the card. You can
also select it and press `Enter`, `Space`, or `F6`. The highlighted border,
editing title, and terminal caret identify the active editor.

Text cards keep their stored size while you type. Long text wraps inside the
card, and the editor follows the caret when it moves beyond the visible area.
`▲` and `▼` indicate hidden rows above or below. Long links and group names use
`◀` and `▶` to indicate hidden text on either side.

| Editing control              | Result                                        |
| ---------------------------- | --------------------------------------------- |
| Type or paste                | Insert content at the caret                   |
| Click text                   | Move the caret to that position               |
| Left/right arrow             | Move by one displayed character               |
| Up/down arrow                | Move between visible wrapped rows             |
| `Home` / `End`               | Move to the start or end of the visible row   |
| `Ctrl+Home` / `Ctrl+End`     | Move to the start or end of the card content  |
| `PageUp` / `PageDown`        | Move by one visible editor page               |
| Scroll over a text editor    | Review hidden rows inside the card            |
| `Enter`                      | Add a line break in a text card               |
| `Ctrl+S`                     | Save a text card                              |
| `Enter`                      | Save a link or group name                     |
| Click outside the card       | Save the edit                                 |
| `Esc`                        | Cancel without changing the Canvas            |

Activating a file card opens the linked file. Using the edit command on a file
card opens that Markdown file directly in the editor, instead of showing the
Canvas JSON.

<Callout>
  Press uppercase `E` only when you intentionally want the complete JSON
  source—for example, to inspect vendor-specific extension fields or repair a
  malformed file. Normal Canvas authoring stays in the visual view.
</Callout>

## Attach and detach connections

Select a card to reveal one `●` connection handle on each side. The `◇` corner
handles resize the card; the `●` side handles create connections. Drag a `●`
handle to another card to create a connection. The connection and its endpoint
sides are saved immediately.

For keyboard-only connection editing:

1. Select the source card.
2. Press `c`.
3. Use arrows or `h` / `j` / `k` / `l` to select the target.
4. Press `Enter` to attach, or `Esc` to cancel.

Click a connection to select it, or use `[` and `]` to cycle through
connections. Press `Delete`, `Backspace`, or `x` to detach the selected
connection. With no connection selected, those keys delete the selected card
and its attached connections.

## Open card targets

Press `o` to open the selected file or link. File paths are resolved inside the
vault; a file card cannot use `..` or another path to escape the vault. External
links use the configured system opener.

## Saving and compatibility

Creating, duplicating, deleting, moving, or resizing cards; editing content;
and attaching or detaching connections are saved atomically. Press `u` to undo
a Canvas change and `Ctrl+R` to redo it. These Canvas-local bindings do not
replace global panel focus (`h` / `l` or left/right), navigation history
(`-` / `=`), `Ctrl+Z` zen mode, or `Ctrl+Y` task view. Ekphos preserves unknown
root, card, and connection fields when it rewrites a Canvas, which keeps vendor
extensions available for other JSON Canvas applications.

If a Canvas cannot be parsed, Ekphos shows the source location and leaves the
file untouched. Press `E` to repair the JSON source.
